    Job files come from /etc/crontab, /etc/cron.d/ and the user crontabs in /var/spool/cron/crontabs/. Every change is backed up to /var/lib/linustart/backups and recorded in the audit log.
    
      
    

      
      
    
        
    
          
    
            
          
    
          
    
            
            
            
          
    
        
    
        
    
        
    
        
    Every change is written to the file, applied with sysctl --system, and rolled back automatically if the kernel rejects it. The runtime column shows what the kernel is using right now, read from /proc/sys. At boot the files in /etc/sysctl.d/ and the system directories (/run, /usr/lib/sysctl.d) are applied in name order, the last one setting a parameter wins (marked "overridden by" elsewhere), and /etc/sysctl.conf is applied only where a 99-sysctl.conf link points to it.
